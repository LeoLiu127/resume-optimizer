# 简历专家 Demo

一个本地运行的 AI 简历优化 Agent WebApp 演示页。

## 启动方式

```bash
npm install
npm run dev
```

## 已实现能力

- 输入目标岗位、行业、公司类型、求职阶段、JD、原始简历、补充信息
- 一键填充示例数据
- 本地 Mock AI 生成完整分析结果
- 左侧流程导航切换 8 个步骤
- 经历追问卡片填写后同步更新最终简历内容
- 支持不同优化倾向的模拟展示
- 支持复制最终简历内容

## 技术说明

- React + Vite
- 所有分析结果均来自本地 mock 数据逻辑，后续可替换为真实大模型 API
