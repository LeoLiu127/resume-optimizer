# 主操作与简历导出重设计

## 背景

当前顶部主按钮名为“岗位解析”，但它实际触发的是完整的智能处理流程：
英文 JD 预处理、JD 解析、简历诊断、匹配分析、经历追问、简历优化、
面试准备、补强建议和最终简历生成。“岗位解析”只描述了其中第一步，
会让用户低估按钮的作用。

导出页目前名为“导出结果”，仅消费中文 `analysis.finalResume`，提供
Classic、Modern、Minimal 三套模板及 PDF、Word 两种格式。用户希望增加
中文或纯英文简历导出，并更新 Classic 与 Modern 的视觉样式。

## 已确认的产品行为

1. 顶部主按钮改名为“开始智能优化”，移到顶部工具栏最右侧。
2. 分析成功后或用户修改输入后，主按钮文案显示“重新生成结果”。
3. 主按钮仍是唯一触发整套 AI 分析的全局主操作；保存岗位、追问生成、
   复制和导出等局部操作继续保留为各自页面内的次级操作。
4. 流程页签“导出结果”改为“简历导出”，页面标题和相关说明同步修改。
5. 导出页增加“中文简历 / English Resume”语言选择。
6. 选择英文时，由 MiniMax 按英文招聘语境重写结构化简历，而不是逐字翻译。
7. 英文结果在当前分析生命周期内缓存；切换模板、PDF/Word 或来回切换语言时
   不重复调用 AI。重新分析后缓存失效。
8. 模板映射保持现有 key 与导出入口稳定：
   - `classic`：替换为“编辑出版型 / Editorial”
   - `modern`：替换为“精准网格型 / Precision Grid”
   - `minimal`：保留现有“极简留白 / Minimal”
9. 三套模板均支持中文和纯英文内容，并保持 HTML 预览、PDF 和 Word 的
   信息层级与视觉方向一致。

## 方案与取舍

### 英文内容生成

#### 方案 A：主分析同时生成中英文

切换语言最快，但每次主分析都会增加输出长度、延迟和截断风险，即使用户不导出
英文简历也会产生额外成本。不采用。

#### 方案 B：导出页按需生成并缓存

首次选择英文时调用独立 AI 接口，成功后缓存结构化英文简历；后续模板和格式切换
直接复用。延迟和成本只发生在真实需要英文简历时，并且不会扩大主分析 Schema。
采用此方案。

#### 方案 C：浏览器端逐字段机器直译

实现简单，但无法处理英文简历常见的动作动词、职责表达、日期和标题习惯，
产出质量不足。不采用。

### 模板方向

用户对三套视觉方案完成比较后确认：

- 编辑出版型替换原 Classic：单栏阅读顺序、杂志式标题层级、克制暖色标记，
  重点保证可信度、阅读连续性和 ATS 兼容性。
- 精准网格型替换原 Modern：深色信息轨配合结构化主内容区，提高信息密度和
  扫描效率。
- 原 Minimal 不变：继续提供黑白、极简、大留白的第三种选择。

## 界面设计

### 顶部主操作

主按钮加入现有 `.topbar-actions` 的末尾，位于“管理”之后，并通过左侧间距或
分隔线与辅助工具区区分。删除独占第二行的 `.topbar-main-action` 布局，收回
无效垂直空间。

桌面端按钮保持右对齐；窄屏允许工具栏换行，但主按钮仍位于操作序列最后，
不得重新落到左侧。处理中显示“智能优化中…”，禁用重复点击。

### 简历导出页

导出页左侧控制区顺序为：

1. 简历语言：中文简历 / English Resume。
2. 选择模板：编辑出版型 / 精准网格型 / 极简留白。
3. 导出格式：PDF / Word。
4. 主导出按钮与状态反馈。

右侧继续显示实时 A4 预览。切换语言后，预览和文件名立即对应当前语言；
英文首次生成期间，预览区显示独立加载状态，现有中文结果保持可用。

模板对用户展示中文主名称与英文副名称，不再使用 Classic、Modern 作为主要名称，
但内部 key 保持不变，避免破坏已有选择与构建器映射。

### 文件名

中文模式：

`候选人_目标岗位_编辑出版型.pdf`

英文模式：

`Candidate_Target_Role_Editorial_EN.pdf`

文件名继续清理操作系统非法字符，并限制单段长度。

## 架构与数据流

### 结构化英文简历

新增独立服务端端点：

`POST /api/analyze/resume-english`

请求：

```json
{
  "finalResume": {},
  "role": "目标岗位"
}
```

成功响应：

```json
{
  "engine": "minimax-m3",
  "finalResume": {},
  "role": "English target role"
}
```

服务端复用现有 MiniMax 客户端和 JSON 提取器。新增英文简历 Prompt，要求：

- 严格保持 `finalResume` Schema，不增加展示专用字段。
- 不虚构数字、职责、项目或技能。
- 公司名、产品名、技术名和已有英文缩写保留原文。
- 中文职位、专业和描述改写成自然的英文招聘表达。
- 日期统一为简洁英文形式；无法确认时保留原值。
- 输出只包含纯英文内容；姓名允许保留用户原始写法。
- 只返回合法 JSON。

服务端对返回结果做结构归一化和必要字段校验；空对象、结构错误、输出截断或
MiniMax 失败均返回明确错误，不回退到伪造英文内容。

### 前端状态

`ExportPanel` 增加：

- `language`：`zh` 或 `en`。
- `englishState`：`idle | loading | ready | error`。
- 当前英文 `finalResume` 与英文岗位名。
- 以当前中文 `finalResume + role` 的稳定序列化结果作为缓存 key。

选择中文时直接使用原 `analysis`。首次选择英文时调用
`ai.generateEnglishResume(finalResume, role)`；成功后构造只替换
`finalResume` 和岗位名的导出数据视图并缓存。模板或格式切换不触发 AI。
接收到新的 `analysis` 时清除旧英文缓存。

`buildResumeView` 继续作为三种预览、PDF 和 Word 的统一输入适配层。
它不得根据语言自行翻译，只负责把已选择语言的结构化数据归一化为模板视图。

### 模板实现

保留 `classic`、`modern`、`minimal` 三个 key 和现有导出服务映射。

- `ClassicPreview`、`ClassicPdfDocument`、`buildClassicDocx` 的视觉实现改为
  编辑出版型。
- `ModernPreview`、`ModernPdfDocument`、`buildModernDocx` 的视觉实现改为
  精准网格型。
- Minimal 三端实现不改版，只补齐语言化章节标题。

模板接收 `language` 或集中生成的章节标签映射，以保证：

- 中文：职业摘要、核心能力、工作经历、项目经历、教育背景等。
- 英文：Profile、Core Skills、Experience、Selected Projects、Education 等。

PDF 与 Word 不依赖浏览器 CSS；三种介质分别实现相同的版式语义，而不是截图导出。

## 错误处理

- 英文生成失败：保留中文预览和全部导出能力；英文区域显示可重试错误。
- 用户在英文生成中切回中文：不中断中文操作；英文请求完成后只写缓存，
  不强制切换当前视图。
- 用户重新运行分析：立即废弃旧英文缓存，防止导出错配内容。
- 未生成分析结果：语言、模板与导出按钮维持禁用状态。
- PDF 字体加载或 DOCX 构建失败：沿用现有导出错误区，显示具体格式失败信息。
- 未知模板 key：继续阻止导出并显示“未知模板”，不得静默切到其他样式。

## 测试与验收

### 自动化测试

1. 主按钮在初始、加载和已有分析三种状态下分别显示：
   “开始智能优化”“智能优化中…”“重新生成结果”。
2. 主按钮在桌面布局位于顶部工具栏最右侧，窄屏换行后仍保持操作序列末尾。
3. `steps` 与导出页标题均显示“简历导出”。
4. 英文接口测试覆盖成功、MiniMax 未配置、无效请求、截断输出和非法 JSON。
5. 英文规范化测试覆盖公司名、缩写、日期、空数组和缺失字段。
6. 导出面板测试确认同一分析只生成一次英文版本；切换模板和格式不重复请求。
7. 新分析到达后旧英文缓存失效。
8. 三个模板在中英文模式下均能生成非空 HTML 预览、PDF Blob 和 DOCX Blob。
9. 文件名包含正确的模板标签、语言标签和扩展名。

### 视觉验收

1. 编辑出版型的 HTML、PDF 和 Word 均保持单栏连续阅读、暖色标记和清晰层级。
2. 精准网格型三种介质均保持约三成信息轨、七成主内容区的网格结构。
3. Minimal 与改动前的主要布局、留白和黑白风格一致。
4. 三套模板用同一份中英文样例检查分页、长公司名、长职位名和 4–6 条 bullet。
5. A4 预览无截断、重叠或溢出；PDF 与 Word 打开后顺序正确、文字可复制。

## 范围边界

本次不新增更多模板、不修改主分析内容、不重做整个应用主题，也不做第三方翻译
供应商切换。英文导出只针对最终结构化简历，不翻译诊断、匹配分析、面试准备或
补强建议页面。
